- There is no demo mode: every workspace page runs on real accounts and PostgreSQL data; the first administrators come from ADMIN_EMAILS or `npm run db:set-role`.
- Store permissions in the user_roles table and link live student records to owners and assigned faculty; enforce record access in authenticated server functions (src/backend, src/lib/*.functions.js) with SQL that checks the caller's roles.
- Keep website navigation shared in PublicLayout and account state in one root AccountProvider so sign-in affordances reflect the current session without duplicate listeners.
- Compose the website assistant from AI Elements with the AI SDK UI-message stream, keeping prompts, full conversation transport and provider calls server-side.
- Store live record mutations and mentor interventions in PostgreSQL; return success only after confirmed writes and invalidate the shared campus query to refresh derived scores.
- Authentication is a bcrypt-hashed password plus a signed JWT in an httpOnly cookie; roles are re-read from the database on every request, never trusted from the token.
- The project is plain JavaScript. src/routeTree.gen.ts is generated by TanStack Router and is the only TypeScript file.
